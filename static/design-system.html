When to use what

  • Violet → Pink gradient (135deg): primary CTAs, "selected" states, primary brand surfaces.
  • Cyan: secondary actions, links, "ticker A" theme on dashboards.
  • Warm gold: paid / mentorship / "elite" markers, hover shimmer, success on warm panels.
  • Mint green: positive metrics (high score, ✓), "ticker B" on dashboards.
  • Hot red: live indicator, errors, danger destructive actions only.

4. Background system

Two layers: (1) static deep-purple gradient on body, (2) three soft floating blobs absolutely positioned, blurred, color-mixed. The blobs gently drift on an 18s loop and give the page subtle life without distracting.

body {
  background:
    radial-gradient(circle at 20% 10%, #2a1166 0%, transparent 50%),
    radial-gradient(circle at 80% 80%, #5a1c8c 0%, transparent 45%),
    linear-gradient(135deg, var(--bg-1), var(--bg-2));
  background-attachment: fixed;
}

.blob { position: fixed; border-radius: 50%; filter: blur(80px); opacity: 0.45; z-index: -1; }
.blob.b1 { background: #ff6bd6; }  /* pink, top-left */
.blob.b2 { background: #6be6ff; }  /* cyan, bottom-right */
.blob.b3 { background: #b46bff; }  /* violet, center */

Always include overflow-x: hidden on body — blurred blobs extending past the edge will trigger horizontal scroll otherwise.

5. Glass cards

The core surface treatment. Every meaningful block of UI lives inside one. backdrop-filter: blur(20px) against the floating blobs is what creates the depth.

A glass card

Translucent white over a blurred backdrop, soft 1px border, generous 20–24px radius, deep ambient shadow.

.card {
  background: rgba(255,255,255,0.05);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255,255,255,0.12);
  border-radius: 24px;
  padding: 2rem;
  box-shadow:
    0 20px 60px rgba(0,0,0,0.4),
    inset 0 1px 0 rgba(255,255,255,0.1);
}

Variants: --radius-lg (20px) for dense dashboard panels, --radius-xl (24px) for hero/feature cards. Never solid backgrounds — break the glass aesthetic.

6. Buttons

Pill-shaped, gradient-filled primary actions with hover lift + shadow growth. Ghost buttons for cancel/back.

Pattern

.btn-cta {
  background: linear-gradient(135deg, var(--accent), var(--accent-2));
  color: white;
  padding: 0.9rem 1.8rem;
  border-radius: var(--radius-pill);
  font-weight: 600;
  box-shadow: 0 8px 24px rgba(180,107,255,0.4);
  transition: transform 0.2s, box-shadow 0.2s;
}
.btn-cta:hover { transform: translateY(-2px); box-shadow: 0 12px 32px rgba(255,107,214,0.5); }
.btn-cta:disabled { opacity: 0.4; filter: grayscale(0.4); cursor: not-allowed; }

Disabled state always uses opacity + grayscale, never a flat gray. Keeps the brand visible even when inactive.

7. Form inputs

Dark interior, accent border on focus, danger border on error, animated inline error message.

Format email tidak valid

Labels above, never as floating labels (too clever, hurts scanning). Errors appear with a slide transition only after first blur — don't yell at users while they're still typing.

8. Tappable options

The core interaction primitive of the survey. Big tap target, emoji-led, animated hover lift, gradient-filled when selected with a check circle.

Each option must start with a relevant emoji — visual anchor + scan speed. Single-select questions (singleBest: true) get radio behavior; multi-select stays toggle.

Guiding principle: fast and snappy on interaction (200–400ms), slow and ambient on background (5–18s loops). Never animate at 1–2s — uncanny valley between snappy and ambient.

11. Voice & copy

Language is Bahasa Indonesia, casual. Direct address ("kamu"), no formal "Anda". Use this when writing any user-facing string.

  • Tone: friendly senior peer, not corporate. "Klik aja yang sesuai", "Nggak ada jawaban benar atau salah".
  • Length: short. Questions ≤ 80 chars. Subtitles ≤ 100 chars.
  • Honesty hooks: "Jujur aja", "Realistis", "Pilih yang beneran kamu lakukan" — invite self-honesty over performance.
  • Emoji per question + per option — visual anchor, mood signal. Pick emojis that map literally where possible (🐍 for Python, 🐙 for GitHub).
  • Error messages: actionable, never blamey. "Format email tidak valid" not "Invalid input".
  • Success / done: warm, named, forward-looking. "Makasih, {firstName}! Sampai ketemu di kelas".

Conventions to follow:
- Dark gradient background (deep purple, --bg-1 #0a0418 → --bg-2 #1a0b3a)
  with three blurred floating blob accents (pink, cyan, violet).
- All meaningful surfaces are GLASS CARDS:
  background rgba(255,255,255,0.05), 1px rgba(255,255,255,0.12) border,
  20–24px radius, backdrop-filter blur(20px), deep ambient shadow.
- Primary action: pill button with linear-gradient(135deg, #b46bff, #ff6bd6),
  hover lifts -2px and grows shadow. Disabled = opacity 0.4 + grayscale.
- Accent palette: violet #b46bff, pink #ff6bd6, cyan #6be6ff,
  warm gold #ffd86b, success mint #6bffb4, danger red #ff5470.
- Typography: Inter system stack, tight letter-spacing on display sizes,
  tabular-nums on every animated number.
- All Bahasa Indonesia, casual, "kamu" not "Anda". Use emoji per item.
- Animations: snappy 200–400ms on interaction (Svelte transitions: fly,
  scale w/ elasticOut, slide, fade), ambient 5–18s loops on background
  (blob float, gradient-shift, shimmer). Never 1–2s mid-range.
- Tappable options are emoji-led big chips with hover lift; "selected"
